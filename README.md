# VirtualGasFixer

Windows-приложение **DJI Virtual Gas Fixer** для накопительного управления газом. Имя репозитория — VirtualGasFixer; текущая программа и установщик сохраняют исходные имена файлов.

Программа для Windows 10/11 x64: DJI RC RM330 напрямую по USB или Xbox-контроллер → виртуальный Xbox 360. Одна выбранная ось управляет скоростью изменения газа; после отпускания газ сохраняется. Отдельный DJI RC Emulator для RM330 не нужен.

## Обычная установка

Скачать готовую программу: [установщик v1.0.0 для Windows x64](https://github.com/Flory211/VirtualGasFixer/releases/download/v1.0.0/DJIVirtualGasFixer-Setup-1.0.0.exe). Все файлы и описание доступны на [странице релиза](https://github.com/Flory211/VirtualGasFixer/releases/tag/v1.0.0). Для закрытого репозитория нужен вход в GitHub под аккаунтом с доступом.

Запусти `dist\DJIVirtualGasFixer-Setup-1.0.0.exe` и следуй русскоязычному мастеру. Он предложит папку, добавит программу в меню «Пуск» и список приложений Windows; ярлык на рабочем столе можно выбрать отдельно. Установка выполняется для текущего пользователя, без установки новых драйверов. Подробности — `docs/installer.md` в исходном проекте. Ниже также описан запуск переносимой сборки.

## Запуск готовой программы

Открой `DJIVirtualGasFixer.exe` в папке готовой сборки. Рядом должна оставаться вся папка `_internal`: копировать только EXE нельзя. Python отдельно устанавливать не требуется. Новые драйверы программа сама не устанавливает.

На проверяемом компьютере уже установлены ViGEmBus и WinUSB для DJI BULK Interface. На другом компьютере они могут отсутствовать: в этом случае программа покажет ошибку. Не заменяй драйверы наугад; для RM330 нужен именно BULK Interface, а не MTP или ADB. ViGEmBus больше активно не поддерживается; совместимость с будущими Windows не гарантируется.

## Подключение DJI RC

1. Закрой отдельный DJI RC Emulator, если он запущен.
2. Включи RM330, подключи кабель к нижнему USB-C порту.
3. Выбери «DJI RC — напрямую USB», ось стика и режим. Начальная ось — LY, вертикаль левого стика.
4. Нажми «Подключить выход». Верни выбранный стик в центр; статус должен стать «Обработка включена».
5. Проверь индикатор газа. При стандартной скорости полный ход вверх в течение секунды даёт 0→100%, отпускание удерживает уровень. Если направление обратное, отключи выход и поставь инверсию.

Настройки источника и осей меняются при отключённом выходе. Изменение источника/оси выключает обработку: включи её явно. При выключенной обработке выбранная ось передаётся напрямую и её значение может резко измениться. «Газ 0%» сбрасывает накопленный уровень и снова ждёт центра; для гарантированного нулевого газа обработка должна быть включена.

## Режимы и сохранение

- «Пропорциональный»: скорость зависит от отклонения за пределами зоны центра (начально 5%).
- «Возле упора»: скорость постоянна только за порогом (начально 90%).
- Скорость задаётся в процентных пунктах в секунду: 100 %/с проходит весь диапазон за секунду.
- Запуск и потеря связи имеют независимые настройки «ноль / сохранить»; начально обе — ноль.
- Настройки и уровень сохраняются раз в 2 секунды и при обычном закрытии в `%LOCALAPPDATA%\DJIVirtualGasFixer\settings.json`. После аварийного закрытия могут потеряться последние 2 секунды изменений; при первом запуске или повреждённом файле уровень 0%.
- При обрыве остальные оси центрируются, кнопки отпускаются. При «сохранить» виртуальное устройство остаётся и удерживает газ. После восстановления USB программа ждёт центра. При закрытии виртуальное устройство удаляется: дальнейшее поведение самолёта определяется симулятором.

## AeroFly Professional Deluxe 1.8.0.9

Сначала подключи выход программы, затем запускай Aerofly обычным ярлыком (`flyrun.exe`). Программа не меняет файлы симулятора.

В настройках управления Aerofly выбери виртуальный Xbox 360, созданный программой, и выполни калибровку/назначение каналов. В русских ресурсах этой установленной версии окна называются «Джойстик» (кнопка «Калибровать») и «Распределение каналов» (кнопка «Настройки»). Ниже — требуемый результат; последовательность кликов ещё проверяется на месте:

1. Назначь газ на выбранную в программе ось. Пройди 0%, 50%, 100% кнопкой сброса и удержанием стика; физический центр соответствует удержанию, а не обязательно середине газа.
2. Если мастер требует нейтраль всех осей, перед этим установи газ 50%. Для полного диапазона газ должен пройти от 0% до 100%.
3. Назначь остальные каналы и убедись в правильных направлениях; для направления газа в программе есть инверсия.
4. Проверь: вверх — плавное увеличение; центр — удержание; вниз — уменьшение; 0/100% ограничены.

При прямом DJI другого исходного игрового устройства от пульта нет. В режиме Xbox исходный и выходной контроллеры видны одновременно: оставь в Aerofly назначения только для выходного устройства. Проверь, что движение исходного стика не перебивает удерживаемый газ. Если симулятор смешивает устройства и это нельзя отключить, понадобится отдельно согласованная настройка HidHide; программа его не устанавливает и ничего не скрывает автоматически. До проверки отсутствие конфликта в этом режиме не гарантируется.

## Xbox и выход существующего DJI RC Emulator

Запусти источник (физический Xbox либо отдельный эмулятор), нажми «Найти Xbox», выбери показанный номер исходного Xbox. Затем подключи выход. Программа исключает свой собственный XInput-номер. Если индекс выхода определить не удалось, Xbox-режим не запускается.

При первом подключении старого эмулятора слегка подвигай стики и верни их в центр: у его версии v1.1 наблюдался ненулевой стартовый отчёт ViGEm даже при физических стиках в центре. Пока вход не попадёт в зону центра, новая программа показывает «Верни выбранный стик в центр» и не увеличивает газ.

Из-за возможной перенумерации XInput любое уведомление Windows об изменении устройств останавливает Xbox-источник до ручного переподключения выхода. Это намеренно осторожное поведение; иногда его вызывает подключение другого USB-устройства. Программа никогда сама не выбирает замену отключённому Xbox.

## Сопоставление DJI

Четыре оси: левый горизонтальный → LX, левый вертикальный → LY, правый горизонтальный → RX, правый вертикальный → RY. Колесо камеры за порогом 80% → Y/B; C1 → LB, C2 → RB, Photo → A, Video → X, Fn → Back; дополнительное колесо → D-pad вверх/вниз. Триггеры по умолчанию нулевые. Сопоставление основано на открытом коде эмулятора; фактические кнопки и направления конкретного RM330 требуют проверки движением и нажатием. Не все модели пульта передают эти кнопки одинаково.

## Проверки и исходники

Автотесты: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.

Диагностика готового EXE (полный путь к EXE и файлу отчёта):

```powershell
.\DJIVirtualGasFixer.exe --probe --report .\usb-check.json
.\DJIVirtualGasFixer.exe --self-test-output --report .\output-check.json
.\DJIVirtualGasFixer.exe --integration-test --report .\integration-check.json
```

Окно программы и старый эмулятор должны быть отключены перед USB-диагностикой. Команда output создаёт временный контроллер и отправляет контрольные значения; выполняй при закрытом симуляторе. Результат `ok: true` подтверждает только указанную проверку. Подробности выполненной приёмки — `docs/testing.md` в исходном проекте.

Сборка: Python 3.12 x64, локальное `.venv`, `pip install -r requirements.txt`, затем `python tools/fetch_client.py` (получение только DLL и лицензий) и `powershell -File build.ps1`. Системный драйвер нужен для аппаратных проверок, не для расчётных тестов. Не запускается установщик vgamepad.
