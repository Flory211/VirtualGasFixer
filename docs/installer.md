# Мастер установки VirtualGasFixer 1.0.1

Готовый файл: `dist\VirtualGasFixer-Setup-1.0.1.exe`.

## Как установить

1. Закрой запущенную VirtualGasFixer.
2. Открой файл установщика, нажми «Далее».
3. При желании отметь ярлык на рабочем столе.
4. Выбери папку или оставь предложенную: `%LOCALAPPDATA%\Programs\VirtualGasFixer`.
5. Нажми «Установить», затем «Готово». На последней странице можно запустить программу.

Программа появится в меню «Пуск» и списке установленных приложений Windows. Для обычной установки в предложенную папку права администратора не нужны. Установщик содержит всю программу и не требует загрузок во время установки. ViGEmBus и USB-драйвер пульта не устанавливаются и не заменяются.

## Обновление и удаление

Повторный запуск установщика предлагает прежнюю папку. Перед обновлением нужно закрыть приложение.

Версия 1.0.1 обновляет предыдущую установку на месте: новое имя появляется в меню «Пуск» и списке приложений, прежний EXE и прежние ярлыки заменяются. Если старая версия уже установлена, её папка сохраняется; для новой установки предлагается `VirtualGasFixer`. Настройки прежней версии читаются автоматически, затем сохраняются под новым именем. Старый файл настроек не удаляется.

Удаление: Windows → «Параметры» → «Приложения» → VirtualGasFixer → «Удалить». Также в папке меню «Пуск» есть ярлык «Удалить». Сохранённые настройки в `%LOCALAPPDATA%\VirtualGasFixer\settings.json` остаются для повторной установки.

Удаляются только файлы, входившие в пакет программы, и созданные установщиком ярлыки. Посторонние файлы в папке установки сохраняются. Если файл занят или защищён от удаления, мастер сообщает об ошибке и сохраняет средство удаления для повторной попытки.

## Сборка и проверка для разработчика

В проекте используется переносимый NSIS 3.13. Официальный архив:
`https://downloads.sourceforge.net/project/nsis/NSIS%203/3.13/nsis-3.13.zip`.

SHA-256 использованного архива: `BA63DFFC4410EE89193E1CB5A41989991BD77C61068DA17E3156D136B7B0B3D8`.

Распаковать в `.tools`, затем запустить `build-installer.ps1`. Параметр `-RebuildApp` сначала пересобирает приложение. Сборка генерирует точный список устанавливаемых/удаляемых файлов, без рекурсивного удаления каталога установки.

Интеграционная проверка: `tests\installer-smoke.ps1 -Installer dist\VirtualGasFixer-Setup-1.0.1.exe`. Она устанавливает копию в уникальную тестовую папку проекта, проверяет контрольные суммы всех файлов, регистрацию и ярлыки, затем проверяет ошибку удаления защищённого файла и успешную повторную попытку. Пользовательские настройки и добавленный посторонний файл должны сохраниться. Проверка отказывается запускаться поверх установленной копии или существующей папки ярлыков.
